DC: LEVEL UP — облачная версия для iPhone + компьютера

ЧТО ВНУТРИ
- index.html: трекер с облачной синхронизацией через Supabase Auth + Postgres REST API
- manifest.webmanifest и sw.js: PWA оболочка
- README_CLOUD_SYNC.txt: пошаговая настройка

ВАЖНО
Эта версия по умолчанию работает локально. Для синхронизации нужно создать бесплатный проект Supabase, выполнить SQL из инструкции и указать Project URL + публичный anon/publishable key в Настройках приложения. Не вставляй service_role/secret key в браузер.

После входа с одинаковым аккаунтом на компьютере и iPhone данные синхронизируются после изменений. Оставь включёнными резервные копии. Не очищай данные браузера, пока не проверишь синхронизацию.
